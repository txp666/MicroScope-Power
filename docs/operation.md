# 使用说明

## 固件烧录

1. 构建固件：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-firmware.ps1
   ```

2. 按住 Pico `BOOTSEL` 接入 USB。
3. 将 `build/firmware-ninja/pico_power_scope.uf2` 拷贝到 Pico 盘符。
4. Pico 自动重启后进入 WebUSB 设备模式。

已烧录过本固件后，可以不用按 BOOTSEL：

1. 打开网页并连接设备。
2. 点击顶部“固件升级”。
3. 确认后设备会停止采集并重启到 BOOTSEL/U盘模式。
4. 把新的 UF2 拷贝到 Pico 盘符。

也可以按住本地滚轮按键再上电，持续约 `1s` 后设备会直接进入 BOOTSEL/U盘模式。
这一路径只是免按键进入 ROM bootloader，不是边运行边写自身 flash 的网络 OTA。

## 发布版本

CI 会自动构建固件。普通 push/PR 只生成 Actions artifact；打 `v*` tag 会创建 GitHub Release 并上传固件资产。

```powershell
git tag v0.2.0
git push origin v0.2.0
```

固件中的版本字段来自 tag。网页连接设备后，“状态”卡片会显示固件版本。

## 打开上位机

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

浏览器打开：

```text
http://127.0.0.1:8000/
```

要求 Chrome 或 Edge。页面打开后点击“连接设备”。

## 量程与电阻

当前有两个量程：

| 网页名称 | 固件 range | 默认电阻 | 说明 |
| --- | ---: | ---: | --- |
| 大量程 | `1` | `1Ω` | 较大电流，SEL=0 |
| 小量程 | `10` | `10Ω` | 较小电流，SEL=1 |

网页输入电阻单位是 `Ω`。点击“应用校准”后，上位机会下发：

```text
SET_SENSE_MOHM_RANGE 1 <大量程电阻mΩ>
SET_SENSE_MOHM_RANGE 10 <小量程电阻mΩ>
```

两个电阻值会保存到 Pico flash，断电后恢复。

## 归零

推荐流程：

1. 让输入处于零电流状态。
2. 根据需要选择自动量程或手动量程。
3. 点击“归零”。
4. 确认当前电流接近 `0 uA`。

注意：

- 两个量程有独立零点。
- 如果只在一个量程归零，切换到另一个量程时可能仍有偏移。
- 手动编辑 `零点 code` 后点击“应用校准”可写入指定量程零点。
- 零点会保存到 Pico flash，断电后恢复。

## 自动量程

自动量程打开时：

- 默认优先从 1Ω 大量程开始采集。
- 大量程信号较小时会切到 10Ω 小量程。
- 小量程接近饱和或偏离零点过大时会切回 1Ω 大量程。
- 切换后会丢弃若干稳定帧，避免把切换瞬间显示成有效波形。

如果被测负载低功耗间歇工作，波形出现大幅跳变可能是负载本身的工作模式，不一定是通信问题。可先接固定电阻验证稳定性。

## 采样率

支持：

- `10 kSPS`
- `20 kSPS`
- `50 kSPS`
- `100 kSPS`

当前实测 100kSPS 更适合该通信时序；如果某个采样率出现明显异常，优先回到 100kSPS 或固定电阻验证。

## 波形查看

常用控件：

- “清屏”：清除网页本地缓存，不影响固件。
- “暂停显示”：停止跟随最新数据，采集仍继续。
- “最新”：回到最新数据。
- “放大/缩小”：调整时间窗口。
- “左移/右移”：查看历史缓存。
- 鼠标滚轮：在曲线上缩放。
- 鼠标拖动：自由平移。
- 自动 Y 轴：按当前可见窗口估计显示范围。
- 手动 Y 轴：取消自动 Y 轴后可固定上下限。

网页保留一段环形缓存，数据很多时绘图按列聚合 min/max，避免每个点都画导致卡顿。

## 双坐标轴

曲线数据内部统一按 `uA` 计算：

- 左侧 Y 轴：`uA`。
- 右侧 Y 轴：同一范围换算为 `mA`。

两个坐标轴只是单位不同，不代表两条数据。

## OLED 本地显示

上位机没有开始采集时，OLED 显示：

- 输出电压，单位 `V`，两位小数显示。
- 当前电流，单位 `UA` / `MA` / `A`。

电压行右侧小字显示当前旋钮步进，只显示数值，例如 `0.01`、`0.1`、`1`。
本地电流读取会使用当前量程、电阻和零点。上位机开始采集后，固件不让 OLED 再读取 ADS8866，避免抢占高速采样。
ADS8866 本地读取带超时保护，通信异常时不会永久阻塞主循环。

## DAC 输出

本地旋钮用于调整 DAC 输出电压：

- 旋转：调整。
- 按住旋转：快速调整。
- 短按：切换步进。

常用步进为 `0.01 / 0.1 / 1 V`。按住旋转时使用快速倍率。
DAC 输出电压会在停止调节约 `1.5s` 后保存，断电后恢复。输出电压显示来自 ADC 实测值，因此可能和设定值略有差异。

## 断电保存

当前保存内容：

- 大量程零点。
- 小量程零点。
- 大量程采样电阻。
- 小量程采样电阻。
- DAC 输出电压。

保存写入 flash 最后一个扇区。采集运行时不写 flash，避免影响高速采样。
